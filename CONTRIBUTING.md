# Contributing Guidelines

## 1. Project Context

The **Enterprise SOC Lab** is a personal engineering portfolio and research documentation repository designed to showcase hands-on security architecture, detection engineering, and incident response methodologies.

---

## 2. Contribution Policy

Because this repository documents a specific, empirical laboratory deployment conducted in a controlled environment, external code or documentation contributions are **not currently accepted or required**.

* **Issues & Discussions**: Constructive feedback, technical questions, and discussions regarding detection engineering concepts, SIEM query tuning, or architecture designs are welcome via GitHub Discussions and Issues.
* **Typo & Formatting Fixes**: If you notice broken links or formatting errors in the documentation, you are welcome to submit a minimal, focused Pull Request addressing only the typographical correction.
* **Architectural Modifications**: Pull requests proposing alternative tools, different network topologies, or new attack simulations outside the empirical baseline will not be merged, as the project preserves the historical integrity of the implemented laboratory environment.

---

## 3. Public-Safe Compliance

Any suggested documentation adjustments must strictly adhere to the project's [Sanitization Policy](file:///e:/project_ca_nhan/lab_cty/docs/PUBLIC_PRIVATE_BOUNDARY.md):
* No real internal IP addresses or private infrastructure addressing.
* No proprietary company or institution names.
* No plaintext credentials, private keys, or raw un-sanitized logs.
